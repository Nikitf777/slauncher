This project is a Minecraft server manager and launcher.
Some of the planned features are:
* Creating servers of different versions and different mod loaders
* Removing servers
* Installing mods (both manually and from sources, like Modrinth and CurseForge)
* Configuring servers
* Launching and stopping servers
* Viewing their logs
* Sending commands to servers

It uses a client-server architecture with a backend built with Rust and Actix Web. Its source code is in the slauncher-backend/ directory.
For now there are no frontends.

jj (jujutsu) is primerily used for version control.
